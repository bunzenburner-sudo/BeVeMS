# BeVeMS-Testversion 0.3.0

Die Datei **BeVeMS-Testversion-0.3.0.zip** herunterladen und vollstaendig entpacken.

Voraussetzungen: **Node.js 24 LTS** und **Docker Desktop** (gestartet).

- Windows: `starten.cmd` doppelklicken.
- macOS/Linux: im entpackten Ordner `sh starten.sh` ausfuehren.
- Nach dem Start auf dem eigenen Rechner `http://localhost:3000` oeffnen.
- Die lokalen Anmeldedaten werden beim ersten Start in `DEMO-ZUGANG.txt` erzeugt.
- Die ausfuehrliche Anleitung steht in der ZIP in `HIER-STARTEN.txt`.

Enthalten sind Quellcode, fixierte Paketversionen, Migrationen, fiktive Demo-Daten und Startskripte. Keine bestehenden Zugangsdaten, Datenbankkopien oder installierten Abhaengigkeiten. Beim ersten Start ist Internetzugriff zum Download von Paketen und PostgreSQL erforderlich.

Echter Microsoft-Versand, FM-Abgleich und Virenscanner benoetigen eine eigene Konfiguration; fuer die lokale Demo sind keine Microsoft-Zugangsdaten erforderlich.

Dieser Branch stellt ausschliesslich das Testpaket zum Download bereit.
